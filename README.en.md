# Energie-SQL-Bench

Reproducible text-to-SQL benchmark in German and English on the SQL Server warehouse of the
[Energiewende-Monitor](https://github.com/HARISPAARTAN/energiewende-monitor): gold SQL and gold result sets,
execution-based scoring, guarded read-only execution and recorded responses from which CI re-derives every
published number offline.

Status: under construction (v0.1.0). Deutsche Fassung: [README.md](README.md).
