# Energie-SQL-Bench

Reproduzierbarer Text-to-SQL-Benchmark auf Deutsch und Englisch auf dem SQL-Server-Warehouse des
[Energiewende-Monitors](https://github.com/HARISPAARTAN/energiewende-monitor): Gold-SQL und Gold-Ergebnisse,
ausführungsbasierte Bewertung, abgesicherte Nur-Lese-Ausführung und aufgezeichnete Antworten, aus denen CI jede
veröffentlichte Zahl offline neu berechnet.

Status: im Aufbau (v0.1.0). English version: [README.en.md](README.en.md).
