EX: share of items whose result set matches the gold result set (extra columns allowed); EX-strict: same column count. Range: minimum and maximum over repeats. Cost in USD from recorded tokens; EUR at 1.1193 USD/EUR of 2026-10-23.

The German and the English item of one intent are paired, and repeats of the same item are not independent. Accuracy is first averaged per item over its repeats. The 95 % interval is, for every number of repeats, a bootstrap interval over intents (fixed seed); the effective sample size is the number of intents (60), not the number of items (120). McNemar tests run on intents: an item counts as correct when more than half of its repeats are correct, an intent when all its language items are correct.

## Pipeline test (synthetic, no language model)

These runs contain no language model. A deterministic generator answers from the gold SQL and injects fixed, labelled faults (dialect error, hallucinated column, `DELETE`, wrong abstention). They test guard, execution, comparison, self-correction, scoring and replay and are not a model result.
